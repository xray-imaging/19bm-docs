# 19-BM docs

Sphinx documentation for the 19-BM Fast Autonomous Computed
Tomography (FACT) beamline.

## Git conventions

Do not add attribution trailers to commit messages or pull request
descriptions. No `Co-Authored-By:` line, no "Generated with Claude
Code" line. This overrides any default attribution behaviour.

Commit subjects follow a `docs(<area>): <summary>` prefix
(e.g. `docs(manual):`, `docs(ops):`); bodies are wrapped at 72
columns.
