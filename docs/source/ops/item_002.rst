=========================================
Beamline restart / commissioning (CRRT)
=========================================

The 19-BM operations commissioning ("CRRT restart") procedure — the
step-by-step process for bringing 19-BM-FACT back online for
operations. First light in the new beamline configuration is
targeted for the 2026-3 beam cycle.

Document
--------

The full procedure is maintained as a Word document in the project
Box folder:

* `CRRT Restart Procedure 19-BM (v0.1) <https://anl.box.com/s/gtaap3ma7oyvt6blhepoz5neyw9jvmwm>`_
  — ``CRRT Restart Procedure 19-BM_v0_1.docx``
